# service-catalog

Supported services, available products and plans, and scoped catalogue reads.

`ServiceCatalogService` and its private PostgreSQL repository discover enabled airtime, data, TV, prepaid/postpaid electricity, education and individual insurance revisions with bounded keyset pagination. Mobile products retain `networkCode`; non-mobile products use `billerCode` and, for electricity, an explicit meter mode. Prices, denomination limits, fees, validation lifetime, allowance and package validity belong to immutable revisions. Operators may withdraw a revision; changing terms requires a new revision. The runtime role cannot publish products or change financial terms, and migrations seed no commercial catalogue.

The authenticated discovery controller is composed by `PaymentsModule`, alongside quote and submission contracts, so responses can report adapter availability without exposing upstream routing. See the [first-party payment API and recovery guide](../payments/README.md). Reads bypass cache for authoritative pricing and eligibility. `ServiceCatalogModule` exports its service and keeps SQL providers private; it owns no wallet workflow or external provider client.

Education revisions include institution/product purpose, fee/voucher type and beneficiary evidence lifetime. Fixed-premium insurance revisions include reviewable coverage, exclusions, period, cancellation/refund terms, requested insured fields and eligibility lifetime. Only `isEnabled` may change on an existing revision; neither publishing a product nor displaying its terms supplies a provider capability.

Bank transfer profiles define first-party bank identity, country/currency and numeric account length rules. Transfer product revisions bind to one bank profile and carry variable recipient amount limits and fixed fees. Published-bank and product currency must match; withdrawn banks exclude associated products from fresh discovery/quoting while accepted historical payment snapshots remain readable. Bank directory filters include currency/country and bounded keyset pagination; transfer product filters also include bank identity/currency. These authoritative reads use the shared PostgreSQL pool and no cache.
